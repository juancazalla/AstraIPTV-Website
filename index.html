SOBRE EL PROYECTO

Más contexto
para cada título.

Astra IPTV es un reproductor de medios desarrollado por Juan Cazalla Estrella. El contenido procede exclusivamente de las fuentes que añade cada usuario.

Uso previsto de TMDB

La integración de The Movie Database está preparada para enriquecer las fichas de películas y series de la biblioteca del usuario con:

  • Sinopsis, géneros, fechas de estreno y duración.
  • Pósteres, imágenes de fondo y reparto.
  • Valoraciones de TMDB, información de temporadas y referencias a tráileres.

Activación pendiente de credenciales propias de TMDB.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB se utilizará como fuente de metadatos, no como fuente de emisiones. La reproducción es independiente de esta integración. No se afirma ninguna aprobación, certificación ni licencia comercial concedida por TMDB.

ANTES DE EMPEZAR

Las cosas claras.

¿Se puede descargar ya?

Todavía no. La versión para iOS, iPadOS y tvOS está en desarrollo y aún no está disponible en el App Store. Esta web presenta el proyecto y su integración prevista con TMDB.

¿Incluye canales o suscripciones?

No. Astra IPTV no vende ni proporciona canales, listas, películas, series o suscripciones de televisión. Debes añadir tus propias fuentes y disponer de los derechos o permisos necesarios para reproducirlas.

¿Qué ocurre con mis datos?

La versión actual conserva la biblioteca y las preferencias en el dispositivo y guarda las credenciales en el llavero del sistema. No incorpora publicidad ni analítica. Las fuentes y los servicios externos que utilizas reciben las solicitudes necesarias para funcionar.

¿Esta web utiliza cookies o seguimiento?

Esta web no incorpora analítica, publicidad, formularios ni cookies propias. GitHub Pages aloja el sitio y puede registrar datos técnicos de las visitas según su declaración de privacidad.
